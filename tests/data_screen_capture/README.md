# tests/data_screen_capture

**Директория:** `tests/data_screen_capture/`

## Назначение

Набор исходных экранных снимков для deterministic image tests.

## Поддиректории

- `locate/` — снимки области ESOlocate с координатами в имени файла.
- `compass/` — снимки компаса для разных положений стрелки.

Файл `4665_7969.jpeg` лежит также непосредственно в этой директории как отдельный исходный/удобный fixture.

## `create_new_data.py`

Простой бесконечный capture loop:

1. ждать 1 секунду;
2. сделать `ImageGrab.grab()` всего экрана;
3. сохранить JPEG с timestamp в имени.

Использовать на машине с работающей игрой для получения новых fixture.

## Правило при добавлении fixtures

Для capture-алгоритмов лучше хранить:

- исходное изображение;
- описание того, какой UI был включён;
- ожидаемый результат;
- при необходимости разрешение/scale.

Сейчас метаданные находятся главным образом в именах тестовых параметров и самом коде тестов.
