# matrix

**Директория:** `matrix/`

## Назначение

Хранит карту потенциальных рыболовных точек и граф переходов между ними.

## `adjacency_matrix.csv`

CSV использует `|` как разделитель.

Колонки содержат:

- `index` — номер вершины;
- `destination_point` — координата точки;
- `isDestination` — флаг;
- далее — веса/значения матрицы смежности.

Текущий набор данных содержит 8 вершин (`0..7`) и линейную цепочку переходов.

Пример логики:

```text
0 <-> 1 <-> 2 <-> 3 <-> 4 <-> 5 <-> 6 <-> 7
```

Фактический `DiGraph` строится из матрицы в `Destination.load_data()`.

## `destination.py`

`Destination` хранит class-level state:

- `destination_points`;
- `adjacency_matrix`;
- `graph`;
- `current_destination`.

### `load_data()`

Берёт данные из `AdjacencyMatrixParser` и создаёт `networkx.DiGraph`.

### `get_destination_point()`

Возвращает координату вершины с индексом `current_destination`.

### `set_next_destination_point()`

Смотрит соседей текущей вершины, выбирает ребро с минимальным весом. При нескольких равных весах выбирает случайный вариант.

После выбора увеличивает обратный вес на 1 и переключает `current_destination`.

### Почему веса важны

Это не просто кратчайший путь. Вес используется как память о посещениях/выбранных переходах. Увеличение веса должно помогать распределять будущий выбор.

## Особенность текущей реализации

`map_destination` фактически берётся из CSV как целые значения и передаётся в `networkx.DiGraph(np.matrix(...))`. Нужно помнить, что для `DiGraph` ненулевое значение матрицы становится ребром, а число становится его weight.
