# tools/example_UI

**Директория:** `tools/example_UI/`

## Назначение

Это экспериментальный пример UI на CustomTkinter, похожий на demo, на основе которого, вероятно, развивался текущий
`UI/teso_fisher_ui.py`.

## Не является production UI

Приложение содержит демонстрационные элементы:

- sidebar;
- tabs;
- radio buttons;
- checkboxes;
- progress bars;
- scrollable frame;
- placeholder controls.

Оно не связано с TESO Fisher runtime и не должно использоваться как источник истины о текущем интерфейсе продукта.
