# tools

**Директория:** `tools/`

## Назначение

Экспериментальные и вспомогательные scripts, которые не являются основным runtime Fisher.

## Поддиректории

- `draw_graph/` — генерация/просмотр графа.
- `example_UI/` — сгенерированный/экспериментальный пример CustomTkinter UI.
- `update_readme_file/` — старый скрипт для подстановки requirements/test cases в README.

`TextWrapper.py` содержит вспомогательный класс для вывода/перенаправления текста в GUI, но в текущем UI соответствующая интеграция закомментирована.

## Правило

Не следует считать code under `tools/` частью production runtime, пока это явно не подтверждено imports из основного приложения.
