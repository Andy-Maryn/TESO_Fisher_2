# output

**Директория:** `output/`

## Назначение

Содержит собранный Windows executable:

`TESO Fisher UI 1.0.exe`

## Важно

Это бинарный артефакт, а не исходный код. При изменении Python-кода executable сам по себе не обновится.

Историю того, какой commit/исходники использовались для конкретного `.exe`, текущая директория не хранит. Для будущих
сборок полезно добавлять version/build metadata.
