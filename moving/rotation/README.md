# moving/rotation

**Директория:** `moving/rotation/`

## Назначение

Расчёт геометрического угла и перевод коррекции угла в движение мыши.

Основной класс — `Rotation` из `rotation.py`.

## Основные параметры

```python
m = 2.825
b = -2.795
a = 1
```

`m` и `b` задают линейное преобразование между величиной движения мыши и углом. Эти значения могут быть пересчитаны
методом `mouse_sensitivity()`.

## `get_degree(start_point, destination_point)`

Рассчитывает угол между двумя координатами относительно оси X и затем нормализует результат через `_degree()`.

Тестовые примеры показывают convention проекта: горизонтальное направление может возвращаться как `360`, а не `0`.

## `_calibrate(degree, compas_degree)`

Внутренне вычисляет разницу между целевым и текущим углом с wrap-around через тангенс/арктангенс.

`calibration()` затем переводит correction в пиксельное/мышиное движение через `_d2p()`.

## `move_mouse()`

Использует библиотеку `mouse`.

```text
mouse.move(x=correction, y=0, absolute=False, duration=Rotation.a)
```

### Важно

Аргумент `duration` метода сейчас не используется: вместо него всегда применяется `Rotation.a`.

## `mouse_sensitivity()`

Использует `numpy.linalg.lstsq()` для линейной аппроксимации зависимости `mouse movement -> compass degree change`.

## `calculate_mouse_sensitivity()`

Runtime-calibration процедура:

1. снимает начальный компас;
2. для `move` от 1 до 29 двигает мышь;
3. снова снимает компас;
4. вычисляет изменение угла;
5. собирает пары `_x`, `_y`;
6. вызывает `mouse_sensitivity()`.

Это требует работающей TESO и корректного capture окна компаса.
